# Problem 187: Semiprimes
## Task
A composite is a number containing at least two prime factors. For example, 15 = 3 x 5, 9 = 3 x 3, 12 = 2 x 2 x 3.

There are ten composites below thirty containing precisely two, not necessarily distinct, prime factors: 
```math
4, 6, 9, 10, 14, 15, 21, 22, 25, 26
```
How many composite integers, n < $10^8$, have precisely two, not necessarily distinct, prime factors?
## Explanation (ft. C++)
**My initial plan:**
- First, implement the Sieve of Eratosthenes to store all primes below $\frac{10^8}{2}$.
- Run a loop from 4 (the first semiprime) to $10^8$ (the dividends), then run a sub-loop through the prime list (the divisors). If any of the quotient is a prime, then the corresponding dividend is a semiprime.
```cpp
int main(){
    eratosthenes();
    int result = 0;
    for (int i = 4; i < 100000000; i++){
        for (int j = 2; j <= sqrt(i) + 1; j++){
            if (i % j == 0){
                if (prime[j] && prime[i/j]){
                    result++;
                    break;
                }
            }
        }
    }
    cout << result << endl;
}
```
Eventually, it occurs to me that this approach is computationally unviable. While the first part (listing out the prime) is fair enough, the main algorithm is still suboptimal. Maybe we should do the other way around: **multiplying the primes rather than dividing the test subjects.** 

**Second attempt:**
- The Sieve of Eratosthenes can be left untouched, just need a small tweak: `push_back` the primes from the sieve to a brand new array for better execution.
- Initialize `left` and `right` to be the start and the end of the array. Note that they refer to the indices, not the actual values (of the primes). Then run a `while(left < right)` loop:
  - `result += right - left + 1` For a fixed smaller prime `right`, once we find the largest valid `left`, every prime between p and q also works. Count the numbers between them by calculating the distance between the two indices. The results (semiprimes) can not be overlapped since they are the product of two primes.
  - We can find the largest valid `left` by checking if the product is larger than $10^8$ or not. If true, reduce (the index) of `left` to switch to the (smaller) adjacent prime.
  - If `left` was found, update result as aforesaid and update left (index) to be the (larger) adjacent prime. Do not need to update `right` immediately in this case.

```cpp
    int left = 0; int right = array.size() - 1;
    while(left < right){
        if (array[left] * array[right] > 100000000){
            right--;
        }
        else{
            result += right - left + 1;
            left++;
        }
```

## Full solution
```cpp
#include <bits/stdc++.h>
using namespace std;

int prime[100000000/2];

void eratosthenes(){
    for (int i = 0; i < 100000000/2; i++){
        prime[i] = 1;
    }

    prime[0] = prime[1] = 0;

    for (int i = 2; i <= sqrt(100000000/2); i++){
        if (prime[i]){
            for (int j = i * i; j <= 100000000/2; j += i){
                prime[j] = 0;
            }
        }
    }
}

int main(){
    eratosthenes();
    int result = 0;
    vector<int> array;
    for (int p = 2; p <= 100000000/2; ++p) {
        if (prime[p]) {
            array.push_back(p);
        }
    }
    int left = 0; int right = array.size() - 1;
    while(left < right){
        if (array[left] * array[right] > 100000000){
            right--;
        }
        else{
            result += right - left + 1;
            left++;
        }
    
    }
    cout << result;
}
```
