# Problem 214: Totient Chains
## Task
Let $\phi$ be Euler's totient function, i.e. for a natural number $n$, $\phi(n)$ is the number of $k$, $1 \le k \le n$, for which $\gcd(k,n)=1$ .

By iterating $\phi$, each positive integer generates a decreasing chain of numbers ending in $1$.
E.g. if we start with $5$ the sequence $5, 4, 2, 1$ is generated.
Here is a listing of all chains with length $4$:
```math
\begin{aligned}
5, 4, 2, 1 \\
7, 6, 2, 1 \\
8, 4, 2, 1 \\
9, 6, 2, 1 \\
10, 4, 2, 1 \\
12, 4, 2, 1 \\
14, 6, 2, 1 \\
18, 6, 2, 1 \\
\end{aligned}
```
Only two of these chains start with a prime, their sum is $12$.

What is the sum of all primes less than $40000000$ which generate a chain of length $25$?
## Explanation (ft. C++)
This is my plan:
- First, implement the Sieve of Eratosthenes to store all primes below $40000000$. The sieve works by making a list of numbers and crossing out the multiples of each prime number starting from 2, leaving only the primes behind.
- Create a function to calculate the Euler's totient of a number.
- Since all chains end in 1, create a `while n!= 1` loop that repeatedly calculate the Euler's totient of a number until it reduces down to 1 (and count the length of the chain).

*What is the Euler’s totient function, you may ask?*

Euler’s totient function, written as $\phi(n)$, counts how many positive integers from $1$ to $n$ are relatively prime / co-prime to $n$. In simpler terms, $\phi(n)$ = number of integers $k$ between $1$ and $n$ such that $k$ shares no common divisor with $n$ except $1$.
```math
φ(n)= \# \{ {k:1≤k≤n, gcd(k,n)=1} \}
```
**General Formula:**

Given:

$$
n=p_1^{a1}p_2^{a2} ⋯ p_k^{ak}
$$

then:

$$
\phi(n)=n(1−\frac{1}{p_1})(1−\frac{1}{p_2})⋯(1−\frac{1}{p_k})
$$

where $p_1, p_2,⋯,p_k$ are the distinct prime factors of $n.$

The algorithm can be written in C++ as below:
```cpp
int phi(int n){
    int result = n; int p = 2;
    
    while (p * p <= n){
        if (n % p == 0){
            while (n % p == 0){
                n /= p;
            }
            result -= result / p;
        }
        p += 1;
    }
    if (n > 1) result -= result / n;

    return result;
}
```
**Line-by-line explanation:**

- `int result = n, int p = 2`. Start with full count, assume that all numbers from 1 to n are valid. From here, we remove the numbers that share a factor with n. The smallest prime number is 2, so we begin from here.
- `while (p * p <= n)`. We only need to test up to the square root of n, since because any factor larger than that must have a smaller paired factor that we have already tested.
- `if (n % p == 0)`. Check if p is a factor of n.
- `while (n % p == 0) n /= p`. Divide n by p repeatedly until it can’t anymore, (so that it moves to another number later). The explanation for this repeated division will be explained in the example down below.
- `result -= result / p`. Apply totient reduction, removing the fraction of numbers divisible by p. This is equivalent to:
```math
result=result−\frac{result}{p}
```
which is aligned with the aforementioned general formula.
- `p += 1`. Move to the next possible factor. The code checks the next integer. It is not the most optimized version because it checks composite numbers too, but it still works correctly. And this time n has been reduced, and it will be reduced again after every loop.
- `if n > 1: result -= result / n`. After the loop, if n > 1, then the remaining n is a prime factor. So we apply the totient reduction one last time.

**Example:**

- n = 360; $\phi$(360) = 96
- $\Leftrightarrow result = 360 ; \ 360 = 2^3 \times3^2 \times5$
- $p=2 \Rightarrow 360 \rightarrow180 \rightarrow 90 \rightarrow 45$. (it technically removes $2^3$. Euler’s totient formula only needs each distinct prime factor once, therefore the reduction here streamlines the process, enabling the algorithm to move to $3^2 \ and \ 5$. Leaving 360 as it is is okay but not optimal.)
- When n can not be reduced any longer, we move on to the next step: reducing the result according to the rule. We only need `result` and `p` in this step. Note that: `n` is reduced to **find prime factors efficiently, while** `result` is reduced to **calculate how many numbers remain coprime (a.k.a. $\phi(n) - the \ endpoint \ we \ need$).**
- We move $p$ from $2$ to $3$ and repeat the same process. $result$ get updated $(-\frac{result}{p})$ and $n =45 \rightarrow 15 \rightarrow 5.$ At this point we also have removed all the 3’s.
- The loop stop as now $p^2 > n  \ (4^2 = 16>5)$. Therefore, the current result $(5)$ is the final prime factor, and we apply the totient reduction one last time to get that value $1-\frac{1}{5}$ in $\phi(n)$.
- Return the result:
```math
result = result-\frac{result}{2}-\frac{result}{3}-\frac{result}{5} =360-\frac{360}{2}-\frac{360}{3} -\frac{360}{5} = 96
```

## Full solution
```cpp
#include <bits/stdc++.h>
using namespace std;

int prime[40000001];

void eratosthenes(){
    for (int i = 0; i <= 40000000; i++){
        prime[i] = 1;
    }

    prime[0] = prime[1] = 0;

    for (int i = 2; i <= sqrt(40000000); i++){
        if (prime[i]){
            for (int j = i * i; j <= 40000000; j += i){
                prime[j] = 0;
            }
        }
    }
}

int phi(int n){
    int result = n;
    int p = 2;
    
    while (p * p <= n){
        if (n % p == 0){
            while (n % p == 0){
                n /= p;
            }
            result -= result / p;
        }
        p += 1;
    }
    if (n > 1) result -= result / n;

    return result;
}

bool chain(int n) {
    int length = 1;

    while (n != 1) {
        n = phi(n);
        ++length;
    }

    return length == 25;
}

int main() {
    eratosthenes();

    long long sum = 0;

    for (int i = 2; i < 40000000; ++i) {
        if (prime[i] && chain(i)) {
            sum += i;
        }
    }

    cout << sum << '\n';
}
```
