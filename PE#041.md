# Problem 41: Pandigital Prime
## Task
We shall say that an n-digit number is pandigital if it makes use of all the digits 1 to n exactly once. For example, 2143 is a 4-digit pandigital and is also prime.

What is the largest n-digit pandigital prime that exists?
## Explanation (ft. Python)
Let's first ponder about the problem. The highest pandigital is none other than `987654321`, a 9-digit number that use all the digits exactly once. Its permutations, for example, `167489235` or `673821954`, are also 9-digit pandigitals. 

However, there's a catch: the sum from 1 to 9 is 45, which is divisible by 3, rendering any 9-digit pandigital impossible to also be a prime. The same is applied to 8-digit pandigitals, as the sum from 1 to 8 is 36. The sum from 1 to 7 is 28, which is not divisible by 3, making 7-digit pandigitals the likely candidates for the answer we are looking for. If anything, we should delve into them.

The problem ask for the largest number, so I suppose that we should work our way in a descending order. Upon inspecting a pandigital:
- If it is indeed a prime, stop and return that number.
- If not, generate a permutation and continue inspecting.

This can be executed with a technique called **Backtracking**:

*Backtracking is a general algorithm for finding all (or some) solutions to some computational problems, that incrementally builds candidates to the solutions, and abandons each partial candidate (“backtracks”) as soon as it determines that the candidate cannot possibly be completed to a valid solution.*

```py
def backtrack(nums):
    if len(sol) == 7:
        pandigital = int(''.join(map(str, sol)))
        if is_prime(pandigital): return pandigital
        return None
    
    for x in nums:
        if x not in sol:
            sol.append(x)
            result = backtrack(nums)
            sol.pop()
            if result is not None: return result
    return None

nums = [7, 6, 5, 4, 3, 2, 1]
sol = []
```
If you are a beginner (like me!), you may have a hard time comprehending the syntax and the logic behind the code. So let's me explain:
- `nums` stores the digits of the permutation. In this case, from 1 to 7.
- `sol` is the array that stores the current pandigital that we are inspecting, which is computed using recursion. Repeatedly append the number to the array (in the descending order) until the length is 7 (base case). This array is later converted to interger with `pandigital = int(''.join(map(str, sol)))`. A more readable equivalent can be `pandigital = int(''.join(str(x) for x in sol))`.
- `if is_prime(pandigital): return pandigital` checks if the current pandigital is a prime or not. If true, return the number (and exit immediately), else return `None`.
- If the current pandigital is not a prime, we inspect another item by popping the last digit(s) out of the array without initialize the `for` loop by `sol.pop()` (and since the result is still `None`, reappend the numbers in a different order, but still trickling down descendingly). This backtracking method allows one to traverse immediately to the next item in a branch.

We start with the array `[7, 6, 5, 4, 3, 2, 1]`. Convert it to the integer `7654321`. It is not a prime, so let's pop and reappend the array to `[7, 6, 5, 4, 3, 1, 2]`. Continue the process until we reach the answer and exit the code. Spoiler: the answer is indeed a 7-digit pandigital prime, so there is no need for reset the code for other lengths below.
## Full solution
```py
def is_prime(x):
    if x < 2: return False

    s = round(pow(x, 1/2))
    for i in range (2, s + 1):
        if x % i == 0:
            return False

    return True

def backtrack(nums):
    if len(sol) == 7:
        pandigital = int(''.join(map(str, sol)))
        if is_prime(pandigital): return pandigital
        return None
    
    for x in nums:
        if x not in sol:
            sol.append(x)
            result = backtrack(nums)
            sol.pop()
            if result is not None: return result
    return None

nums = [7, 6, 5, 4, 3, 2, 1]
sol = []
print(backtrack(nums))
```
